ปัญหาที่เจอบ่อยที่สุด มักไม่ได้มาจากตัวระบบ แต่มาจากการ์ดความจำ

อย่าใส่เกมเกิน 70% ของการ์ด

เมมโมรี่การ์ดต้องมีที่ว่างให้ตัวควบคุมสลับและจัดการบล็อกข้อมูล ยิ่งการ์ดเต็ม ยิ่งเสี่ยงให้หน่วยความจำบิตเสียหาย แม้จะใช้การ์ดแบรนด์ชั้นนำก็ตาม ลองเลื่อนดูว่าควรเว้นที่ว่างเท่าไร

ใช้ไป 50%เส้นประ = 70%

คำนวณความจุที่เหมาะกับการ์ดของคุณ

ใส่ความจุการ์ดที่มี แล้วดูว่าควรใส่เกมได้สูงสุดเท่าไร หรือใส่ขนาดเกมที่คุณมี เพื่อดูว่าควรซื้อการ์ดขนาดเท่าไร

การ์ดทุกยี่ห้อแสดงความจุจริงน้อยกว่าที่เขียนบนกล่อง (ประมาณ 93%) ตัวเลขนี้ยังไม่หักพื้นที่ระบบของ PlayOS ซึ่งต่างกันไปตามรุ่น

เครื่องค้างหรือหน่วง ตรวจอะไรก่อน

  • พื้นที่การ์ด ถ้าเกิน 70% ให้ย้ายเกมออกก่อน
  • ความเสียหายของไฟล์ เสียบการ์ดกับคอมแล้วตรวจหาข้อผิดพลาด
  • การ์ดไม่ได้มาตรฐาน การ์ดแปลกปลอมมักบอกความจุเกินจริง
  • เกมที่หนักเกินเครื่อง ลองลดการตั้งค่าภาพของเกมนั้น

ทำให้การ์ดอายุยืน

  • เว้นที่ว่างอย่างน้อย 30% ทุกครั้งที่เพิ่มเกม
  • ปิดเครื่องให้เรียบร้อย อย่าถอดการ์ดขณะเครื่องทำงาน
  • สำรองเซฟเกม ไว้บนคอมเป็นระยะ
  • เปลี่ยนการ์ด เมื่อเริ่มเจอไฟล์เสียซ้ำๆ

ดาวน์โหลดเวอร์ชันที่ใช้ได้ตอนนี้

ก่อนดาวน์โหลดจะมีแบบสอบถามสั้นๆ 4 ข้อ ช่วยให้ติดตั้งได้ในครั้งเดียว โดยต้องแตกไฟล์ .7z ด้วย 7-Zip ให้ได้ไฟล์ .img ก่อน แล้วค่อยแฟลชลงการ์ด จากนั้นติดตั้งไฟล์ DTB ให้ตรงรุ่นเครื่องด้านล่าง

ติดตั้ง DTB ผ่านเว็บ

แฟลชการ์ดเสร็จแล้ว เสียบการ์ดค้างไว้ที่คอม แล้วให้เว็บคัดลอกไฟล์ DTB ให้เลย ไม่ต้องหาโฟลเดอร์เอง

1เลือกไดรฟ์ boot ของการ์ด
เบราว์เซอร์นี้ไม่รองรับการเขียนไฟล์ กรุณาเปิดหน้านี้ด้วย Chrome หรือ Edge บนคอมพิวเตอร์ (ไม่รองรับมือถือ / Firefox / Safari) หรือใช้วิธีคัดลอกไฟล์ .dtb เองตามขั้นตอนในผังติดตั้ง
เลือกไดรฟ์ที่เป็นพาร์ทิชัน boot (ไดรฟ์ที่เห็นไฟล์ของ PlayOS หลังแฟลช) แล้วกด "แก้ไขไฟล์/อนุญาต" ที่เบราว์เซอร์ถาม ถ้าเบราว์เซอร์ไม่ยอมให้เลือกไดรฟ์ ให้ใช้วิธีคัดลอกเอง
2เวอร์ชันที่ตรวจพบ
3เลือกรุ่นเครื่องของคุณ
4ไฟล์ DTB ที่จะติดตั้ง
ติดตั้งเสร็จแล้ว
กดถอดไดรฟ์อย่างปลอดภัย แล้วใส่การ์ดเข้าเครื่องได้เลย

คำถามที่พบบ่อย

เจอปัญหา? ลองเช็กตรงนี้ก่อน ส่วนใหญ่แก้ได้ในไม่กี่ขั้นตอน

ติดตั้งแล้วหน้าจอดำ ทำไงดี

ส่วนใหญ่เกิดจากลงไฟล์ .dtb ไม่ตรงรุ่น ให้เข้าโฟลเดอร์ที่ตรงกับรุ่นเครื่องของคุณ คัดลอกไฟล์ .dtb ไปวางไว้หน้าแรกของไดรฟ์ boot (หรือเลือกผ่านสคริปต์ในไดรฟ์ boot) แล้วเปิดเครื่องใหม่

แฟลชเสร็จแล้วเครื่องไม่ติด / ไม่บูต

ตรวจว่าแตกไฟล์ .7z ให้ได้ไฟล์ .img แล้วค่อยแฟลช (ไม่ใช่แฟลชไฟล์ .7z ตรง ๆ), ไฟล์ .dtb ตรงกับรุ่นเครื่อง และลองแฟลชใหม่หรือเปลี่ยนการ์ดอีกใบ

แตกไฟล์แล้วขึ้นว่าไฟล์ชำรุด

ไฟล์ที่ดาวน์โหลดไม่สมบูรณ์ ให้โหลดใหม่อีกครั้ง แล้วแตกไฟล์ด้วย 7-Zip

ลิงก์ Google Drive โหลดไม่ได้ / ขึ้นว่าเกินโควตา

ลองใหม่ภายหลัง หรือกดทำสำเนาลงไดรฟ์ของตัวเอง แล้วดาวน์โหลดจากสำเนานั้น

ควรเลือก PlayOS 3.0 หรือ PlayOS-X

PlayOS 3.0 สำหรับ R36S แท้ ส่วน PlayOS-X สำหรับเครื่องโคลน ให้เทียบชื่อเมนบอร์ดของเครื่องกับรายการอุปกรณ์ที่รองรับของ PlayOS 3.0 และ PlayOS-Xก่อนดาวน์โหลด

ลงไปแล้ว เข้า PlayStation และเครื่องอื่น ๆ แล้วไม่มีเสียงหรือเข้าไม่ได้

ให้ไปตั้งค่าใน RetroArch

อัปเดต OTA ทำยังไง

ลงเกมยังไง

เข้าแอป Store แล้วเลือกเกมที่ต้องการติดตั้งได้เลย

โหลดเกมมาแล้ว เอาเข้าเครื่องยังไง

เข้าแอปไฟล์ หาไฟล์เกมที่โหลดมา กดปุ่ม B แล้วหาคำว่า Play Install จากนั้นเลือกเครื่องเกมให้ตรงกับเกมที่โหลดมา

จะแฟลชทับใหม่ เซฟเกมจะหายไหม

อาจหายได้ ควรแบ็กอัพเซฟเกมจากหน้า Save Game ก่อนแฟลชทับเสมอ

PlayOS-X เชื่อมต่อบลูทูธไม่ได้ / แอปค้างบ้าง

เป็นข้อจำกัดที่ทราบแล้วของ PlayOS-X ยังไม่มีวิธีแก้ในตอนนี้

ลงไปแล้วการ์ดเมมเสีย / เครื่องเสียหาย ใครรับผิดชอบ

ทีมงานไม่มีส่วนรับผิดชอบต่อความเสียหายของอุปกรณ์ ทีมงานดูแลเฉพาะซอฟต์แวร์เท่านั้น หากสงสัยว่าการ์ดเสีย ลองแฟลชใหม่ด้วยการ์ดอีกใบเพื่อเช็กก่อน
