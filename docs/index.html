ติดตั้งเกม จัดการเซฟ แชร์ไฟล์ผ่านไวไฟ และฟังเพลงพื้นหลัง — ทุกอย่างที่เครื่องพกพาของคุณควรทำได้ รวมไว้ในที่เดียว ลื่นไหลตั้งแต่เปิดเครื่อง

ดาวน์โหลด PlayOS 3.0 สำหรับ R36S แท้ ดาวน์โหลด PlayOS-X สำหรับเครื่องโคลน

สองระบบ เซอร์วิสเดียวกัน

เลือกเวอร์ชันให้ตรงกับเครื่องของคุณ ฟีเจอร์หลักเหมือนกันทั้งคู่ ต่างกันที่ระดับความเสถียรตามฮาร์ดแวร์ที่รองรับ

PlayOS 3.0

ออกแบบมาสำหรับเครื่อง R36S แท้ — เวอร์ชันใหม่ล่าสุด

Performance & Hardware

  • แก้ปัญหาตั้งค่า CPU/GPU governor แล้วไม่ยึดค่าที่ตั้งไว้
  • เพิ่ม CPU Grade ในหน้า Performance Settings
  • RAM governor ทำงานตั้งแต่ตอนบูตเครื่อง
  • แก้ GPU Max Freq ลดลงเองเมื่อกดปุ่มขวาในหน้าตั้งค่า
  • แก้ตาราง CPU/GPU opp ในทุก dtb
  • แก้การคาลิเบรต BatteryPlus
  • ตัดไดรเวอร์ 8192cu ที่ซ้ำซ้อนออก

Wi-Fi & OTG

  • แก้ race condition ตอนสลับโหมด wifi/otg
  • ยืนยันแล้วว่า OTG ใช้งานได้จริง
  • เชื่อมต่อบลูทูธได้

PlayOS-X

พอร์ต PlayOS 3.0 มาสู่สภาพแวดล้อมของเครื่องโคลน

สิ่งที่ยังไปไม่ถึง

  • ยังเชื่อมต่อบลูทูธไม่ได้
  • การใช้งานแอปพลิเคชันบางครั้งอาจเกิดอาการค้างได้บ้าง
OS-X คือการพอร์ต PlayOS 3.0 มาให้ทำงานบนสภาพแวดล้อมของเครื่องโคลน ทีมงานจึงขอไม่รับผิดชอบต่อบั๊กที่เกิดขึ้นเฉพาะในเวอร์ชันนี้

ทั้งสองเวอร์ชันยังมีบั๊กที่สืบทอดมาจาก dArkOS ต้นทางซึ่งยังแก้ไม่ได้ในตอนนี้ และไม่ใช่ความรับผิดชอบของทีม PlayOS

จัดการเกมได้ในไม่กี่แตะ

ฟีเจอร์หลักที่ทั้งสองเวอร์ชันใช้ร่วมกัน

  • ติดตั้งเกมจากไฟล์ ZIP

    กด Play Install แล้วเลือกเครื่องเกมให้ตรงกับเกมที่ติดตั้ง ไม่ต้องรู้เรื่องโฟลเดอร์รอมเลย

  • จัดการเซฟเกมในที่เดียว

    แบ็กอัพ ลบ หรือแชร์เซฟเกม ทำได้ง่ายในหน้า Save Game เดียว

  • ติดตั้งเซฟเกมทันที

    เลือกเกมให้ตรงกับเซฟ แล้วกดติดตั้งได้เลย

  • All Game

    ลบเกมหรือแชร์เกมจากหน้าจัดการเกมเดียว

  • Wifi Share

    แชร์ไฟล์ไร้สายผ่าน Wi-Fi แบบเดียวกับ AirDrop

  • Game Share

    แชร์เกมพร้อมเมทาดาต้าผ่าน Wi-Fi

  • SMB

    เชื่อมต่อ NAS ส่วนตัวได้ง่าย ๆ

  • Terminal

    สำหรับใส่ชุดคำสั่งเมื่อคุณต้องการควบคุมเพิ่มเติม

แอปในตัวที่ครบจบในเครื่องเดียว

ไม่ต้องพึ่งเครื่องมือแยก ทุกอย่างที่ต้องใช้ประจำ อยู่ในระบบแล้ว
